# TritonLens 0.2.0

This update improves professor matching and historical-grade context inside UC San Diego TSS.

## Changes

- Direct-source ratings and course-by-professor historical grade records.
- Historical term selection with term-specific GPA and grade distributions.
- Independently displayed RMP profiles for reviewed same-person identities; ratings are not pooled.
- Reviewed short names, middle names and preferred names, including explicit source-name bindings.
- Three verified cross-person profile associations separated while preserving the original grade histories.
- Clear unavailable and partial-data states; no invented student sample sizes or normalized missing percentages.

## Install or update

Download **TritonLens-0.2.0.zip** from the release assets and extract it into a permanent folder. Open `chrome://extensions`, enable **Developer mode**, select **Load unpacked**, and choose the folder containing `manifest.json`.

For an existing installation, replace its files, click **Reload** on the extension, and refresh TSS. Avoid keeping two enabled copies. The ZIP includes `INSTALL.txt`; GitHub's automatically generated source archives need a local build.

## Data notes

The main direct RMP snapshot was retrieved on 2026-10-29. Individual profiles retain their own displayed source dates. Historical-grade coverage is partial and varies by course and term. Missing or uncertain matches remain unavailable, and historical results are not predictions.

The existing **Data snapshot — source permissions pending** disclosure remains in the interface. This release does not claim new redistribution permission or UCSD affiliation.
