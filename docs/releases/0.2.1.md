# TritonLens 0.2.1

This patch removes the snapshot/permission banner from instructor detail cards.
Empty mode labels no longer leave a blank paragraph above the ratings.

Ratings, historical grades, source links and update dates are unchanged.

## Install or update

Download **TritonLens-0.2.1.zip** and extract it into your permanent extension
folder. In Chrome, open `chrome://extensions`, click **Reload** on TritonLens,
and refresh TSS. For a first installation, enable **Developer mode**, click
**Load unpacked**, and select the extracted folder containing `manifest.json`.
Do not enable two copies at once. The ZIP includes `INSTALL.txt`.

## Data notes

The data snapshot is unchanged from v0.2.0. Source links and observation dates
remain visible. Historical coverage is partial, missing matches can remain
unavailable, and historical results are not predictions. Source permissions
remain pending; removing the interface banner does not change that status.
