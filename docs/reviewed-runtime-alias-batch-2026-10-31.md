The manifest binds each alias to an exact retained ID/name, source ID/department
and owned course marker. The helper requires a unique, fresh source observation
from UCSD, unique profile ownership including alternates, and exactly one owned
marker history. It vetoes exact collisions and possible middle-omitted forms
belonging to another record. These relaxed forms only block acceptance; they
never establish identity. Numeric rating values are not pinned.

Import checks already-promoted aliases before reconciliation or grade matching.
If a guard fails for an alias already on its expected or explicitly redirected
owner, the import stops for revalidation and the previous snapshot is preserved.
A final application after refresh catches newly introduced conflicts. A failed
new rule is reported rather than accepted. This deliberately favors withholding
an uncertain update over publishing a contradictory match.
