# TritonLens Icon

The source artwork was created with OpenAI's built-in image-generation tool
on 2026-09-15. No external logo or reference image was used.

Prompt: A bold simple navy circular lens/magnifying-glass silhouette with a
small gold accent arc on the lens rim, navy handle angled down-right.
Centered square composition, about 80% canvas coverage, white plain background.
Deep navy #142C4E, warm gold #E4B343, white. Strong silhouette and thick strokes
readable at 16 pixels. No text, letters, UCSD logo, trident, seal, watermark,
gradients, shadows, 3D, borders, or fine details. One original flat icon.

The generated source is `tritonlens-icon-source.png`. PNG exports in `icons/`
were resized using Windows System.Drawing with high-quality bicubic sampling.
Only the four small PNG exports are included in the extension build; the
source artwork and this note are not runtime files.
